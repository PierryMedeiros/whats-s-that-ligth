# Fase 16: Save e progresso

**Marco:** Sistemas
**Status:** rascunho. Refine com o usuário antes de começar (escopo, critérios de pronto e bugs prováveis).

## Objetivo

Salvar a campanha e o perfil do jogador, do jeito mais simples.

## Escopo inicial

- Campanha no PC do host, com 3 espaços; perfil local com os cosméticos.
- Salvar a ilha ao chegar nela; baú, carteira e upgrades o tempo todo.
- Entrar e sair a qualquer momento; sair no meio reinicia a ilha; o host saindo encerra a partida.
- Formato de save simples e com versão.
