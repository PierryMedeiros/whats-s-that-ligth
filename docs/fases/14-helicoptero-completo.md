# Fase 14: Helicóptero completo

**Marco:** Sistemas
**Status:** rascunho. Refine com o usuário antes de começar (escopo, critérios de pronto e bugs prováveis).

## Objetivo

Dar a cada jogador algo para fazer durante o voo.

## Escopo inicial

- Estações: conserto com silver tape, canhão de tralha, guincho e reviver.
- Modo pairar para o solo; quebras durante o voo e eventos de viagem.
- Upgrades: motor, remendos, baú, guincho e canhão.
- Barulho do rotor abafando as vozes.
